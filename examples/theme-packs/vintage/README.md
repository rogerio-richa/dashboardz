# Vintage, an example theme pack

A warm paper-and-brass theme with one design of its own: `vintage-dial`, a gauge drawn as a brass
dial, with a setting of its own (needle style). It is the worked example in
[Make a theme pack](../../../docs/theme-packs.md). Check it with:

```bash
node hub/scripts/check-pack.mjs examples/theme-packs/vintage --previews /tmp/vintage-previews
```
